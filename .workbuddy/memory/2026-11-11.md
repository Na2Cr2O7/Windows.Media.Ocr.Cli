# 2026-11-11

## 修复 Windows.Media.Ocr.Cli 编译错误（21 errors → 0）

根因：UwpDesktop 10.0.14393.3 包内的 UwpDesktop.targets 使用旧版 SDK 布局
`References\<契约名>\<契约版本>\*.winmd`，新版 Windows SDK 已改为
`References\<SDK版本>\<契约名>\<契约版本>\*.winmd`，导致 60 个引用无法解析，并与 csproj 中
（同样过期、指向 10.0.22000.0 的）引用冲突 → CS0731 / CS1069 / CS0246 / CS0103。

改动仅限 `Windows.Media.Ocr.Cli/Windows.Media.Ocr.Cli.csproj`：
- 新增 `WindowsSdkReferencesRoot` / `WindowsSdkRefVersion` 属性，按 26100 → 22621 → 22000 → 19041 自动选本机已装 SDK。
- FoundationContract 用 `$(WindowsSdkRefVersion)`；UniversalApiContract 用 `\*\` 通配（契约版本号随 SDK 变化，HintPath 不支持通配，故用 Reference Include 通配）。
- 新增 `Windows` facade（UnionMetadata\Facade\Windows.WinMD）与
  System.Runtime.WindowsRuntime(.UI.Xaml) 引用；后者本机无 net48 引用程序集，HintPath 指向
  `$(WINDIR)\Microsoft.NET\Framework\v4.0.30319`（GetAwaiter 扩展方法所在）。
- 新增 Target `RemoveBrokenHintPathReferences`（BeforeTargets=ResolveAssemblyReferences），
  剔除 HintPath 不存在的引用，屏蔽 UwpDesktop 包中失效的重复引用。

验证：`dotnet build -c Debug/Release -t:Rebuild` 均 0 warning 0 error；exe 运行 `-s` 与
`-o res.txt x.png` 正常（识别结果 “9·哪位科学家发现了电磁感应现象？”）。

注意：本机 Visual Studio 18 的 MSBuild.exe 被安全策略拦截，只能用 `dotnet build` 验证。
遗留问题（非编译错误）：Program.cs 中 `-o` 未做越界检查；`#if DEBUG` 会用 `..\..\x.png` 覆盖命令行参数。
